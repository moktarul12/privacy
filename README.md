# DromoMinds App Privacy Policies

Public privacy policy pages for Google Play and App Store listings.

## Live site

After GitHub Pages is enabled (Settings → Pages → Source: **GitHub Actions**):

- **Hub:** https://moktarul12.github.io/privacy/
- **Kiddo:** https://moktarul12.github.io/privacy/kiddo/

Use the Kiddo URL in Play Console → Store listing → Privacy policy URL.

## Add another app

1. Create a folder, e.g. `my-app/index.html`
2. Add a card link on `index.html`
3. Commit and push — Pages redeploys automatically

## Structure

```
privacy/
├── index.html          # lists all apps
├── kiddo/index.html    # Kiddo policy
└── .github/workflows/pages.yml
```
